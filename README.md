# GalAnonim — Bezpieczna Anonimizacja Dokumentów (Wydanie Publiczne)

Oficjalne, publiczne repozytorium dystrybucyjne instalatorów aplikacji desktopowej **GalAnonim** dla systemu Windows.

## 📦 Pobieranie najnowszej wersji
Instalator (.exe) dla systemu Windows x64 można pobrać bezpośrednio w sekcji [Releases](../../releases).

## 💻 Wymagania systemowe
- Windows 10 / 11 (64-bit)
- WebView2 Runtime (wbudowany w Windows 11 lub instalowany automatycznie)
